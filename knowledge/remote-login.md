# Step Code 远程服务器 / SSH 终端登录账号

核实日期：2026-10-19，依据公开文档。

已核实：可通过 SSH 进入服务器后运行 step。没有本地浏览器时，运行 step login --no-browser，终端会给出授权链接；在另一台有浏览器的设备（电脑或手机）打开该链接，完成 Step Plan 登录授权，远程终端中的 Step Code 即完成账号登录。
