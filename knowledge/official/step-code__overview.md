# Step Code 概览

Step Code 是阶跃星辰推出的终端编程智能体（CLI），用于阅读和修改代码、执行命令，以及处理软件开发任务。

## 开始使用

* [快速开始](/docs/zh/step-code/quickstart)：安装、登录并完成首次文件分析。
* [升级](/docs/zh/step-code/installation)：更新程序、选择版本或卸载。
* [登录与模型](/docs/zh/step-code/configuration/models)：配置账号、计费通道与模型。
