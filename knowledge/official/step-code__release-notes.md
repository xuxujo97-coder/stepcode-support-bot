# 版本记录

## v0.1.5

2026 年 10 月 16 日

### 新功能

* 用量面板：新增 `/usage` 命令，提供总览与账户两个标签页：总览展示近期活跃热力图和每日 token 用量，账户页查询个人 Step Plan 剩余额度与重置时间。`/usage overview`、`/usage account` 可直接打开对应页。
* 状态面板：新增 `/status` 命令，一屏查看当前模型、思考档位、权限模式、工作目录和账户信息。
* 任务自查：在 `-p`/JSON 非交互模式中，加 `--completion-review` 可让 Agent 收尾前对照原始任务自查一遍，检查是否做全、接口与边界是否覆盖、测试是否跑过；发现问题先修再总结。

### 优化

* 编辑后验证：`edit_file` / `write_file` 的 `then_run` 改走与 `run_command` 一致的执行路径，超时、输出上限和审批规则与 `run_command` 相同。
* 无界面模式计划审批：`-p`/JSON 非交互模式下提交计划后，若无法直接询问用户，会明确返回计划内容并停止。

### 修复

* 技能冲突提示：修复同一技能同时安装于 `~/.agents/skills` 和 `~/.claude/skills` 时启动刷屏的问题。
* 无套餐账户登录：修复没有套餐的账户登录后无法使用的问题，现在会引导改用 API Key 登录。
* Workflow 重试与并发：修复 workflow 重试与限流误判的问题，按错误类型而非错误文本判断是否重试；同时修复 workflow 与并行子代理同时运行可能超过并发上限的问题。
* Workflow 恢复与失败上报：修复断点恢复时单个调用失败会拖累后续调用全部重跑的问题；失败节点和回调错误现在会出现在最终结果中。

## v0.1.4

2026 年 10 月 12 日

### 新功能

* 新增 CLM（Context Language Models）上下文管理。长对话接近上下文上限时默认启用，由模型选择性精简较早的上下文，原始会话日志不被覆盖；精简失败时回退到原有的摘要压缩。`/clm` 提供 `status`、`on`、`off`、`diff`、`reset` 子命令管理状态，`/clm-compact` 主动请求模型整理上下文，相关模型用量计入会话统计。
* 权限模式调整为 Ask、Approve for Me 和 Full Access。Ask 在修改文件或运行命令前询问；Approve for Me 自动执行常规操作，对检测到的危险命令或无法完整分析的命令仍要求确认；Full Access 允许直接执行风险命令，不再逐次确认。开启 Full Access 前需确认风险，可选择仅本次会话生效或记住选择。

### 优化

* 思考档位统一使用 `/effort` 调整，原 `/thinking` 命令已移除。
* 重新打开同一会话时，自动恢复此前设置的 Ultracode 开关及状态栏提示；新会话仍默认关闭。

### 修复

* 修复首次启动时 StepPage 尚未就绪即连接失败、导致当前会话无法使用网页发布功能的问题。StepPage 准备失败不影响 Step Code 的其他功能，后续启动时会重试。
* 修复安装或升级后重新打开终端可能提示找不到 `step` 命令的问题。
* 修复在用户主目录下启动时同一插件被重复识别、错误提示存在插件覆盖冲突的问题。
* 修复在全局配置中禁用 MCP 服务后，同名插件声明仍可能使其被重新发现的问题。
* 修复工具已经完成、界面却仍显示 Running、Reading 或 Editing 的问题。
* 修复不同项目路径映射到同一会话目录时，会话列表混入其他项目记录、`--continue` 继续到错误项目会话的问题。
* 修复子代理多步骤任务返回结果不完整、后台任务完成后未继续处理，以及长报告被截断的问题；同时修复任务状态显示错误、列表闪烁和进度通知刷屏的问题。
* 修复 Git 安装在自定义目录时误用 WSL 环境运行命令、导致找不到 Windows 中已安装工具的问题。
* 修复 Windows 下 Git Bash 后台命令退出失败、日志为空的问题。

## v0.1.3

2026 年 10 月 9 日

### 新功能

* 新增 Step Plan 远程登录。在 SSH、远程服务器或容器中运行 `step login --no-browser`，会返回完整的授权链接，可在本机或其他设备的浏览器中打开并完成登录，不依赖本地回调端口。
* `edit_file` 与 `write_file` 新增可选参数 `then_run`：文件修改成功后直接运行验证命令并返回结果，无需再单独发起一次验证调用。
* 新增 `--completion-check git-committed` 选项。在 `-p` 或 JSON 模式下，检查本轮改动是否已提交、是否还有未提交文件，以及是否已给出最终答复；未满足条件时会在原会话中提醒 Agent 继续完成，默认最多追加两轮。配合 `--completion-review` 可再进行一次自查，两者共用追加轮次。

### 优化

* 可通过 `STEP_CODING_AGENT_PLAN_DIR` 将计划文件存放在工作区之外，计划文件不会进入代码提交，也不影响工作区状态检查。

### 修复

* 修复已有 Skill 未被自动扫描的问题。`~/.claude/skills`、已信任项目的 `.claude/skills` 与 `~/.stepcode/skills` 现在会自动加载，无需手动配置路径。
* `run_command` 默认超时调整为 120 秒，可通过 `timeout_ms` 参数指定其他值，减少命令长时间无响应导致任务挂起的情况。
* 修复 Linux 下子进程残留导致任务持续等待的问题；命令被系统信号终止时，会正确报告为失败状态。
* 修复命令输出被缩短时完整日志路径或退出状态丢失的问题。退出码、超时或中止原因会一并保留，便于 Agent 查看完整日志后继续排查。
* 修复多次压缩上下文时已有历史摘要未被保留的问题，长任务可以继续使用此前总结的工作信息；同时修复摘要输出超过模型允许上限的问题。
* 修复 Ultracode 欢迎提示与命令入口不一致、缺少使用帮助与命令补全，以及开启状态在常见终端宽度下不可见的问题。
* 新增 `/ultracode` 命令，用于开启、关闭和查看多代理协作状态；原 `/ultraloop` 命令保留，两者功能相同。

## v0.1.2

2026 年 9 月 30 日

### 新功能

* 新增 `--non-interactive-denial continue` 选项。在非交互运行中（如 `-p` 模式），需要人工确认的危险操作被拦截后，将失败原因反馈给 Agent，由其尝试更安全的方式继续执行任务。默认值仍为 `terminate`，即终止任务；两种策略均遵循原有权限限制。

### 优化

* 插件市场的插件列表支持搜索，并移除同名重复项。在交互界面添加市场时显示进度，支持取消，添加成功后进入插件列表。
* 过长的工具返回文本以预览形式呈现，并提供全文文件路径，减少模型上下文占用。
* 对话中仅展示最近一次成功的任务计划更新，减少重复内容；恢复会话时同样生效。
* 优化单行输入时使用上方向键浏览历史记录的行为。全屏模式新增 `Ctrl+End` 快捷键，可返回底部并跟随新输出。

### 修复

* 修复启动或切换 Step 模型时，思考级别被强制设置为最高级别的问题。
* 修复 Skill 扫描卡住，以及 Skill 命令无法识别换行输入的参数的问题。
* 修复内置上下文压缩后丢失已加载 Skill 指令的问题。
* 上下文压缩的摘要请求超限时，尝试缩减旧历史记录并重试。
* 修复已安装插件的 Skill 和提示词命令未加载的问题，重新加载资源后即可使用。
* 修复插件 MCP 的配置识别、服务器名称识别和登录授权复用问题；本地 MCP 服务器默认从插件目录启动。
* 修复 MCP 分页工具列表加载不完整，以及后加载的可用 MCP 工具和扩展工具无法被搜索到的问题；工具列表随服务器通知更新。

## v0.1.1

2026 年 9 月 24 日

### 新功能

* 首次启动时自动预装 StepPage 插件；用户主动卸载后不会重复安装。

### 优化

* 减少子代理任务列表的频繁重绘，减轻闪烁，提升任务信息的可读性。
* macOS / Linux 安装完成后新增启动提示，引导用户运行 `step`。
* 更新中英文 README，补充 StepPage 发布说明与演示。

### 修复

* 修复正式安装版中 Workflow 和 Ultraloop 无法使用的问题，工作流沙箱由 `isolated-vm` 切换为 QuickJS WebAssembly。
* 修复 Workflow 在未等待异步任务、并行任务运行较久及资源清理等场景下的异常退出和错误超时。
* 修正 Step Plan 联网搜索的计费路径，改用订阅对应接口。
* 修复已登录用户仍被插件诊断提示缺少 `STEPFUN_API_KEY` 的问题。
